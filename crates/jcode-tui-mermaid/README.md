# jcode-tui-mermaid

_TUI component_

Mermaid diagram rendering for terminal display. Renders mermaid diagrams to PNG, then displays them via `ratatui-image` (Kitty, Sixel, iTerm2, or halfblock — auto-detected). Includes adaptive PNG sizing, pre-loaded stateful protocol during content prep, and a fit mode for small terminals.
